# Scorsaire : publier mes pages (modèle)

Ce dépôt est un **modèle** : il sert à mettre gratuitement sur Internet les pages que [Scorsaire](https://letournedosrossini.github.io/scorsaire-editeur/) exporte avec une **vidéo YouTube** (partition synchronisée sur la vidéo). Scorsaire ne demande **aucun mot de passe** : vous déposez vous-même le fichier sur votre dépôt.

Le [manuel de Scorsaire](https://letournedosrossini.github.io/scorsaire-lecteur/manuel/) explique le reste.

## En cinq étapes

1. **Créez un compte GitHub** (gratuit) sur <https://github.com> si vous n'en avez pas.
2. **Créez votre dépôt à partir de ce modèle** : bouton vert **Use this template** en haut de cette page, puis **Create a new repository**. Choisissez un nom (par exemple `mes-partitions`) et laissez **Public**.
3. **Activez GitHub Pages** dans votre nouveau dépôt : *Settings* › *Pages* › *Build and deployment* › *Source* : **Deploy from a branch** › *Branch* : **main**, dossier **/ (root)** › **Save**.
4. **Dans Scorsaire** : *Fichier* › *Exporter* › **Publier sur GitHub…**. Écrivez le nom de votre dépôt (`votre-nom/mes-partitions`), puis : ① téléchargez la page, ② ouvrez la page d'envoi de GitHub et glissez-y le fichier, puis appuyez sur **Commit changes**, ③ copiez l'adresse de la page.
5. **Attendez quelques minutes** (parfois une demi-heure : GitHub construit le site), puis ouvrez l'adresse :
   `https://votre-nom.github.io/mes-partitions/nom-du-fichier.html`

## Bon à savoir

- Seules les pages qui contiennent un **lien YouTube** se publient ainsi, jamais des fichiers audio (trop lourds pour une page web).
- Un dépôt gratuit est **public** : tout ce que vous y mettez est visible par tout le monde. Pensez aux droits d'auteur de ce que vous publiez.
- Pour **mettre à jour** une page, envoyez de nouveau un fichier **du même nom** : il remplace l'ancien.
- GitHub limite l'envoi par le navigateur à 25 Mo par fichier.

## Besoin d'aide ?

Dans la fenêtre « Publier sur GitHub » de Scorsaire, le bouton **Copier le texte d'aide pour une IA** copie un texte à coller dans un assistant IA (ChatGPT, Claude, Gemini…) : il vous guide pas à pas. Il ne doit **jamais** vous demander de mot de passe ni de « token » : ne les écrivez pas dans la conversation.

# Scorsaire: publish my pages (template)

This repository is a **template**: it puts, for free, on the Internet the pages that [Scorsaire](https://letournedosrossini.github.io/scorsaire-editeur/) exports with a **YouTube video** (a score synchronised with the video). Scorsaire asks for **no password**: you drop the file on your own repository yourself.

The [Scorsaire manual](https://letournedosrossini.github.io/scorsaire-lecteur/manuel/) explains the rest.

## In five steps

1. **Create a GitHub account** (free) at <https://github.com> if you do not have one.
2. **Create your repository from this template**: the green **Use this template** button at the top of this page, then **Create a new repository**. Choose a name (for example `my-scores`) and keep it **Public**.
3. **Turn on GitHub Pages** in your new repository: *Settings* › *Pages* › *Build and deployment* › *Source*: **Deploy from a branch** › *Branch*: **main**, folder **/ (root)** › **Save**.
4. **In Scorsaire**: *File* › *Export* › **Publish on GitHub…**. Write the name of your repository (`your-name/my-scores`), then: ① download the page, ② open the GitHub upload page and drag the file onto it, then press **Commit changes**, ③ copy the address of the page.
5. **Wait a few minutes** (sometimes half an hour: GitHub builds the site), then open the address:
   `https://your-name.github.io/my-scores/file-name.html`

## Good to know

- Only pages that hold a **YouTube link** are published this way, never audio files (too heavy for a web page).
- A free repository is **public**: everything you put in it is visible to everyone. Think about the copyright of what you publish.
- To **update** a page, upload a file with the **same name** again: it replaces the old one.
- GitHub limits uploads from the browser to 25 MB per file.

## Need help?

In the “Publish on GitHub” window of Scorsaire, the **Copy the help text for an AI** button copies a text to paste into an AI assistant (ChatGPT, Claude, Gemini…): it guides you step by step. It must **never** ask for a password or a “token”: do not type them in the conversation.
